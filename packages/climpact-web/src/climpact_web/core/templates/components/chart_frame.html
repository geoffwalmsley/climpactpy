{% load i18n ui %}{% comment %} Frame for a chart (#71, #75): title, text summary, legend, the plot area (a skeleton until the chart script draws into [data-chart-plot]) and the fallbacks every chart has: a table view and a CSV download. Parameters: id, title, summary, legend (list of {label, token}, token a --chart-* name), height (CSS length), heading (the title's heading level, default 3), csv_href, table_template (included as the table view), and for an interactive chart (#75): data_url (a chart data URL, see TECHNICAL.md "Charts"; the page loads the scripts with {% load charts %}{% chart_scripts %}) and image_src (a static image shown without JavaScript, e.g. the run's PNG). With data_url, the summary, legend and CSV link left out are filled in from the data, and without table_template the table view is built from the data when opened. {% endcomment %}
