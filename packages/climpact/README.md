# climpactpy

A Python port of [Climpact](https://github.com/ARCCSS-extremes/climpact), the R software for
calculating indices of daily climate extremes for station and gridded data. The package is
imported as `climpact` and installs the `climpact` command.

See the [repository](https://github.com/geoffwalmsley/climpactpy) for usage and the
technical notes (`TECHNICAL.md`).
