The form and the cells are plain links and GET forms, so it works without JavaScript; htmx swaps only this fragment (gridded:explore), and the response's HX-Push-Url puts the results page's address for it in the history. The cell's series is an interactive chart (#75): chart_frame with data from gridded:series_json (series_json), the static SVG as the noscript fallback and _series_table.html as the table view. Clicking a map cell swaps this fragment; charts.js hydrates the new chart on htmx:load. {% endcomment %}
