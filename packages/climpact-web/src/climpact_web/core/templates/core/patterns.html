{% translate "Colour" %}

{% blocktranslate trimmed %} Each colour has one job. Ink is for actions: primary buttons and the current tab. Links are blue and underlined. The brand blue is only for the logo, focus rings and selection. Status colours are only for the verdict and run state, always with an icon and a label. The theme hues mark data: Heat, Cold, Rain and Drought, and a neutral for "Also measured". The trend scale colours a significant decrease or increase, and the coverage steps a year's missing days. Every text and background pair meets WCAG AA in both themes, and the theme hues and chart colours stay apart for colour-blind readers (both checked by tests from the token values). Charts outside the browser read chart-palette.json. {% endblocktranslate %}
