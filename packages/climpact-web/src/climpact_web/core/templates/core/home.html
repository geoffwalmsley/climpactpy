{% translate "About the indices" %}

{% blocktranslate trimmed %} The indices describe how often, how long and how intensely extremes occur: the hottest day of the year, warm spells, the longest dry period, heavy rainfall and more. They are defined by the Expert Team on Sector-specific Climate Indices (ET-SCI) and calculated the same way as in Climpact for R, so results can be compared between countries. {% endblocktranslate %}
