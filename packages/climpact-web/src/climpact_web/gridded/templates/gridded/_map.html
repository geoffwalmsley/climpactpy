{% load i18n ui %}{% comment %} A gridded run's Map (#295, #296, the GridMap board): the index rail, the map and the cell pane, across the whole window as the station Indices. Every control is a link or a GET form on the run's address (gridded.map_page), so it works without JavaScript; js/gridded-map.js swaps this block in place (X-Climpact-Part: map) and the pane alone when a cell is chosen (X-Climpact-Part: pane), reads out the cell under the pointer and moves the selection with the arrow keys. The map is a PNG with one pixel per cell (gridded:map_png, in the theme's colours; on Trend each cell several pixels a side, with a dot where the 95% interval excludes zero) under an SVG of the coastline, places, axes and the selected cell. The view (Year, Base mean, Anomaly, Trend, #296) needs the run's trends.nc: without it, or for a monthly or day-of-year file, the three are shown unavailable and the reason is said.
