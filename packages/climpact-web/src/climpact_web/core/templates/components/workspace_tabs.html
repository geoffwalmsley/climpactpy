{% load i18n ui %}{% comment %} Workspace tabs (#179): a station's sections, Quality, Results and Files (#198), as tabs under its name. Each tab is its own page, so this is navigation (a list of links, the current one aria-current="page"), not an ARIA tablist: the keyboard moves between them with Tab, and each opens its page. It reuses the tabs component's look. Each tab has a status: done, needs attention, out of date, running, not started or not available yet. Quality's shows the verdict of the checks instead (#222): Ready, Usable or Fix first in the verdict's tint, with the count of values that look wrong ("Usable · 21"), and "Checking…" while they run; on a phone the verdict is its icon on the tint, so the three tabs fit on one line at 320px (the word and count are still read). The status is an icon of its own shape and a word (shown for the states that need the user, read by screen readers for all), never colour alone. A tab not available yet is not a link. Parameters: tabs (stations.workspace.sections: key, label, url, state, state_label, icon, word_shown, current, count, count_label), label (optional, the navigation's name). {% endcomment %}
