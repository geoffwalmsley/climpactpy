{% load i18n ui %}{% comment %} Workspace tabs (#179): a station's sections, Data, Quality, Results and Files, as tabs under its name. Each tab is its own page, so this is navigation (a list of links, the current one aria-current="page"), not an ARIA tablist: the keyboard moves between them with Tab, and each opens its page. It reuses the tabs component's look. Each tab has a status: done, needs attention, out of date, running, not started or not available yet. The status is an icon of its own shape and a word (shown for the states that need the user, read by screen readers for all), never colour alone. A tab not available yet is not a link. Parameters: tabs (stations.workspace.sections: key, label, url, state, state_label, icon, word_shown, current), label (optional, the navigation's name). {% endcomment %}
